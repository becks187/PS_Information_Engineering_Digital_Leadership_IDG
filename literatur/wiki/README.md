# Wiki – Notizen zur Literatur

Markdown-Notizen pro Paper. Konvention:

- **Dateiname**: `<author-year-shorttitle>.md` (z. B. `rueckel-2024-cio-roles.md`)
- **Verlinkung zur Quelle**: `[[../raw/<exakter-dateiname>.pdf]]`
- **Abbildungen**: in `pictures/` ablegen, im Markdown via `![[pictures/<file>.png]]`

## Vorlage

```markdown
---
title:
authors:
year:
type: paper | report | chapter
themen: [digital-leadership, idg, ...]
---

# {{title}}

**Quelle:** [[../raw/<file>.pdf]]

## Kernaussage

## Methodik

## Relevante Konzepte für unser Framework

## Zitate / Notizen
```

Aktuelle Abbildungen siehe `pictures/`.
