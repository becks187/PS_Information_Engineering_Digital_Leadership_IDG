# Literatur – Index

Einstiegspunkt für die Literaturarbeit des Projekts **Digital Leadership & Inner Development Goals** (Gruppe G4).

## Struktur

```
literatur/
├── raw/      # Original-PDFs und Quelldokumente (read-only Inputs)
├── wiki/     # Markdown-Notizen, Zusammenfassungen, Abbildungen (Obsidian)
└── index/    # MOCs, Übersicht, Status (dieses Verzeichnis)
```

- **raw/** — wissenschaftliche Quellen als PDF/DOCX. Dateinamen entsprechen den Originalen. Nichts hier direkt editieren.
- **wiki/** — pro Paper eine `.md`-Notiz (Titel als Dateiname), die auf das PDF in `raw/` verlinkt. `wiki/pictures/` enthält Framework-Abbildungen.
- **index/** — diese Übersicht plus thematische Maps-of-Content (MOCs).
